# Feature-Dokumentation

Pro Feature eine Datei. Sie beschreibt, **was das Feature kann** und **welche
Dateien dazugehören** — quer durch alle sechs Schichten.

Das ist die Antwort auf die Frage, die beim Weiterarbeiten am häufigsten
kommt: „Wo muss ich anfassen, wenn ich am Kursplan etwas ändern will?"

## Regeln

- Dateiname ist der Feature-Name, kleingeschrieben, mit Bindestrich:
  `kursplan.md`, `online-shop.md`, `terminanfrage.md`
- Angelegt wird sie, **sobald das Feature begonnen wird** — nicht danach.
  Eine halb ausgefüllte Datei ist besser als keine.
- Vorlage: [`../templates/feature-doku.md`](../templates/feature-doku.md)
- Beim Ändern eines Features wird `Zuletzt geprüft` mit angepasst. Eine
  Dokumentation, der man nicht ansieht, wie alt sie ist, wird nicht geglaubt.
