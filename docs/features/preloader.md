## Was kann man damit

Beim Laden jeder Seite zeigt die Website kurz den animierten SCHWITZKASTEN-
Preloader. Sobald alle Ressourcen geladen sind, wird der Ladebildschirm weich
ausgeblendet und aus dem Dokument entfernt.
